## 目的
出典: 端末からの入力（会話 7442c727、2026-11-25 23:36、発言 86cfe4bc）
出典: 端末からの入力（会話 7442c727、2026-11-25 23:39、発言 4bc0da95）
要旨（Claude の要約）: マイルストーンと `next` の表示が更新のたびに点滅して邪魔なので、点滅しないようにする。点滅するのは、ほかのワークスペースの行も含む右側のサイドバー全体。

## いまの方針
Windows の Orca には、WSL の開発フォルダーとしての読み込みをやめ、fork の `wsl-host` を通常のプラグインとしてインストールする。そのために、Windows にインストールされたプラグインが WSL の distro とホームを自分で探すようにする。あわせて、更新のたびにカードが薄くなる表示と、並びが変わった行とカードの作り直しをなくす。

## 判明した事実
- サイドバー全体の点滅の原因は、Orca が 60 秒ごとにパネルのフレーム（webview）を作り直すこと。Orca の描画プロセスの生成時刻を 110 秒測ると、23:42:12、23:43:12、23:44:12 に新しいものが作られた。本体の描画プロセスは 20:44 から同じものだった（2026-11-25、Orca のデスクトップ）。
- 作り直しの仕組み（Orca の配布物のコードを読んだ）: 開発フォルダーのパネルの URL には通し番号が付き、変わるとフレームが作り直される。通し番号は、ファイルの監視の登録が成功するたびに上がる。監視がエラーで終わると、Orca は 60 秒ごとの点検で登録し直す。
- WSL のフォルダー（`\\wsl.localhost\...`）では、Orca に同梱の `@parcel/watcher` の登録は成功し、その約 1 ミリ秒後に `Failed to read changes` のエラーを返す（Orca のバイナリを Node として動かして測った、2026-11-25）。だから点検のたびに通し番号が上がる。
- 監視を止める設定は、読んだ範囲では見つからなかった（開発フォルダーの監視の有無を決めるのはチームの方針だけ）。
- 通常のインストールでは監視が無く、パネルの URL の番号は中身のハッシュなので、中身が変わらなければ変わらない（コードを読んだ。実機ではまだ確かめていない）。
- インストールしたプラグインのフォルダーは Windows 側になる。直す前のコードは、フォルダーのパスだけから WSL を見分けていた。
- 新しく出たカードと位置がずれたカードは、押下を受け付けない 1.5 秒のあいだ薄く表示され、そのあと戻っていた。エージェントが複数あるワークスペースでは、1 枚が増えるか消えるたびに、残りのカードも薄くなっていた。
- パネルの差分の適用は要素を並び順で対応させていたため、行やカードが 1 つ増えるか順番が変わると、後ろの要素をすべて作り直していた。
- 直した `findWslHost` は、実機の Orca のバイナリを Node として動かすと、約 0.4 秒（3 回）で Ubuntu とそのホームを見つけた。Orca がワーカーの起動を待つ上限は 10 秒。
- 直した差分の適用は、Chromium（`moveBefore` あり）で、並べ替えても要素とスクロール位置を保った。

## 判断の経緯
### 2026-11-25 採用: 開発フォルダーとしての読み込みをやめ、通常のインストールで動くようにする
- 出どころ: Claude の判断（実際の切り替えはリーダーの承認を得てから行う）
- 理由: 点滅の引き金は、WSL のフォルダーで監視が続かないこと。プラグインのコードからは監視に触れない。トレードオフは、更新が `plugin dev reload` から `plugin install`（push したコミットの取得と承認）に変わることと、`plugin dev request` などの開発用のコマンドが使えなくなること。
- 状態: 有効

### 2026-11-25 棄却: Windows のフォルダーに写して、開発フォルダーとして読み込む
- 理由: 監視は続くが、WSL からの写しを保つ手間が増え、WSL の見分けの修正も同じだけ要る。
- 状態: 有効

### 2026-11-25 棄却: フレームの作り直しはそのままにし、前の表示を保存してすぐ描く
- 理由: 新しいプロセスが描き始めるまでの空白は消えない。
- 状態: 有効

### 2026-11-25 棄却: Orca の分離したフレーム（`experimentalPluginIsolatedFrames`）を切る
- 理由: 番号の入った URL は使われなくなるが、プラグインの分離を弱める設定で、ほかのプラグインにも及ぶ。
- 状態: 有効

### 2026-11-25 採用: 押下を受け付けない 1.5 秒のあいだも、カードの見た目を変えない
- 出どころ: Claude の判断
- 理由: 薄くして戻す表示が、更新のたびの点滅になる。押下を受け付けない仕組みは残す。トレードオフは、その 1.5 秒に押しても何も起きないことが、ポインターの形でしか分からないこと。
- 状態: 有効
